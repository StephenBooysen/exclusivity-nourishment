Mobile web app — design walkthrough

Intermittent Fasting Companion

Three screens cover the full loop: pick a strategy and plan length, run today's fast from a live dashboard, then review history. All three stay wired to one shared state below — start a plan on Setup and the Dashboard mockup updates immediately, exactly like the real app would. Built entirely on the Organic system: cream ground, terracotta for active/primary states, sage as the quieter second voice.

What each field does
Fasting strategy — four cards (16:8, 20:4, OMAD 23:1, 5:2). Selecting one swaps the fields below and every downstream calculation on Dashboard and History.
Fasting days (5:2 only) — toggle which weekdays are full fasting days; the rest are normal eating days.
Fast begins at — a time picker (daily strategies only). Eating-window open/close times are read-only and recompute from strategy + this start time.
Plan length — 1 week or 1 month; drives the "Day X of Y" counter on Dashboard and the History window.
Start fasting plan — commits the settings and starts today's fast immediately, handing off to the Dashboard.

What each field does
Progress ring — % of the current fasting window elapsed; fills clockwise as the fast continues.
Stage label — plain-language phase (Digesting → Fat-burning → Deep fast) from elapsed hours. Informational estimate, not medical guidance.
Start / End fast early — begins the countdown from Setup's start time, or ends the current fast ahead of target and logs it to History.
Started / Elapsed / Eating opens — quick readout pulled straight from the plan created on Setup.
Notes — timestamped log tied to this fast; add mood, hunger or energy entries any time. They travel with this session into History.
